# Schema-witness research decision

The bounded fresh-agent comparison failed its preregistered usefulness gate.
No product was activated or priced. AgentToolbox remains an honest catalog with
zero active products; the platform's x402 adapter remains unavailable for live
payments.

[The regression](regression-report.md) establishes a real schema-conversion
counterexample in pinned public software. [The comparison](comparison-report.md)
tests a precomputed report on two correlated debugging tasks, with a competent
baseline given the same source, schemas, validators and runnable local server.
All four agents completed correctly. Aggregate command count and observed time
improved, but diagnosis commands increased from 9 to 11, failing the conjunctive
gate. Single observations, answer-bearing treatment material and unavailable
token counts prevent a general productivity or demand claim.

A possible future experimental utility would accept bounded original and
converted JSON schemas and return a concrete JSON instance validated by two
pinned validators as converted-valid and original-invalid, together with exact
schema hashes and reproducible diagnostics. Its objective success criterion
would be that executable contradiction; it could not promise that a witness
exists, a model/provider accepts the schema, or the caller saves time. No such
hosted utility was implemented because the agreed usefulness gate failed.
There is no defensible paid price from this study; retain the evidence as free
research until independent utility and willingness to pay are established.

The frozen archives contain scripts, pinned source/licenses, inputs, raw results,
preregistration, prompts, command logs, adjudication and hashes. They exclude
installed dependencies. Read each archive's README before reproduction; some
comparison scripts retain the original Mac paths. Recomputing recorded metrics
does not create new independent observations. No provider or payment call was
made by the experiment scripts.
